# Local DM Sans files

These unmodified static TrueType files are the normal 400, 500 and 600 faces
returned by the official Google Fonts CSS request previously imported by
`warm.css`. They are served locally so the mint page needs no font service.
The original weights, normal style and `font-display: swap` are preserved.

Source CSS: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600&display=swap
Retrieved: 2026-10-15
