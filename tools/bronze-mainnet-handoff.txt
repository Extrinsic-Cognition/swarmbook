Bronze terms
$10 opening target, converted once to a fixed SOL deposit using a fresh
Coinbase SOL/USD quote. It is not a live USD peg. 150 places; commit window
1080000 slots; reveal window 216000 slots. Buyers commit their deposit,
return to reveal, then settle and claim an allocation or recover their

Run on NewMac, where the tested binary is preserved. These are OWNER commands.
Agents may run prepare / verify / publish, but not deployment or open.

1. In your own terminal, set paths to signers you control. Do not send them
   here. The program signer must derive the exact program address above.
   The authority signer must derive the exact authority address above.
   Keep the deployment buffer signer for recovery if deployment is interrupted.

   BRONZE_AUTHORITY_SIGNER='/absolute/path/to/your-existing-authority.json'
   BRONZE_PROGRAM_SIGNER='/absolute/path/to/your-existing-program.json'
   BRONZE_BUFFER_SIGNER='/absolute/path/to/your-deployment-buffer.json'
   BRONZE_WORKTREE='~/code-ec/house/.worktrees/bronze-mainnet-build'
   BRONZE_ARTIFACT="$BRONZE_WORKTREE/poleis/program/poleis_treasury/target/deploy/poleis_treasury.so"
   BRONZE_SOLANA='~/.local/share/solana/install/releases/stable-515465dd278366f3785dc75e5cce3165edbe316f/solana-release/bin/solana'
   BRONZE_TOOL="$BRONZE_WORKTREE/embertide-app/ui/intro/dyson-society/tools/bronze-mainnet.mjs"

2. Confirm signer public addresses locally and fund the authority on mainnet
   from your wallet. Check the artifact checksum before deploying:

   shasum -a 256 "$BRONZE_ARTIFACT"
   "$BRONZE_SOLANA" address --keypair "$BRONZE_AUTHORITY_SIGNER"
   "$BRONZE_SOLANA" address --keypair "$BRONZE_PROGRAM_SIGNER"

3. Owner only: deploy the exact binary with the exact program identity.

   "$BRONZE_SOLANA" program deploy "$BRONZE_ARTIFACT" \
     --url mainnet-beta \
     --keypair "$BRONZE_AUTHORITY_SIGNER" \
     --fee-payer "$BRONZE_AUTHORITY_SIGNER" \
     --upgrade-authority "$BRONZE_AUTHORITY_SIGNER" \
     --program-id "$BRONZE_PROGRAM_SIGNER" \
     --buffer "$BRONZE_BUFFER_SIGNER" \
     --max-len 390616 --commitment finalized

   Keep preflight and feature verification enabled. Do not use --final.
   If interrupted, inspect the transaction and retained buffer before retrying.

4. Prepare a NEW launch plan after deployment. Use a new output filename

   BRONZE_PLAN="$BRONZE_WORKTREE/poleis/program/poleis_treasury/target/bronze-mainnet-owner-plan.json"
   /opt/homebrew/bin/node "$BRONZE_TOOL" prepare \
     --artifact "$BRONZE_ARTIFACT" --out "$BRONZE_PLAN"

   Review the displayed digest, fixed SOL deposit and terms in the plan.

   /opt/homebrew/bin/node "$BRONZE_TOOL" open \
     --artifact "$BRONZE_ARTIFACT" --plan "$BRONZE_PLAN" \
     --payer-keypair "$BRONZE_AUTHORITY_SIGNER" \
     --approve-plan 'PASTE_THE_REVIEWED_PLAN_DIGEST_HERE'
